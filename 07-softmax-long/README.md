# Softmax

В этой задаче вам предлагается реализовать обобщение сигмоиды на многомерный случай.
В дальнейшем мы будем называть это обобщение софтмаксом (en. Softmax)

**Обратите внимание**: в этой задаче предлагается реализовать софтмакс, чтобы он работал эффективно в случае **достаточно большой размерности** (порядка нескольких десятков тысяч и больше).
Эффективная работа в других конфигурациях нас будет интересовать в других задачах.

### Сигмоида

Сигмоида - это монотонная нелинейная функция, преобразующая вещественные числа в числа на интервале `(0; 1)`

$$
\sigma(x) = \cfrac{1}{1 + e^{-x}}
$$

### Softmax

Софтмакс - это обобщение сигмоиды на многомерный случай.

Если нам дан вектор из $N$ элементов $x = {x_1, x_2, \ldots, x_N} \in \mathbb{R}^N$, то для каждой софтмакс записывается следующим образом:

$$
Softmax(x) = \left\{\cfrac{e^{x_1}}{C}, \cfrac{e^{x_2}}{C}, \ldots \cfrac{e^{x_N}}{C}\right\} \in [0; 1]^N,
$$

где нормировочная константа $C$ выбирается таким образом, чтобы сумма элементов в результирующем векторе была равна единице.

Нетрудно заметить, что $C$ вычисляется аналитически: $C = \sum_{i=1}^N e^{x_i}$

Таким образом, если $y = Softmax(x)$, то мы получаем, что:
$$
y_i \ge 0
\\
\sum_{i=1}^N y_i = 1
$$

**Пример**
```cpp
x = {     100.0f,      101.0f,      102.0f,      103.0f,      104.0f};
// y == softmax(x)
y = {0.01165623f, 0.03168492f, 0.08612854f, 0.23412165f, 0.63640864f};
```

**Замечание**: Для больших подробностей вы можете найти реализацию Softmax на CPU в тестах.

### Задание

Вы должны реализовать одну функцию со следующей сигнатурой:

```cpp
void Softmax(size_t rows, size_t cols,
             const float* d_input_matrix, size_t input_stride,
             float* d_out_matrix, size_t out_stride,
             cudaStream_t stream);
```

**Пояснения**:
* `rows` обозначает число входных векторов, для которых надо посчитать Softmax
* `cols` обозначает размерность каждого входного вектора
* соотвественно, входные и выходые данные лежат в виде матриц, которые имеют логические размерности `rows x cols` и лежат в row-major формате
* `d_input_matrix` и `input_stride` задают расположение входной матрицы в памяти
* `d_out_matrix` и `out_stride` задают расположение выходной матрицы в памяти
* `stream` используется для запуска кернелов в отдельном, недефолтном стриме

**Гарантии**:
* `cols % 4 == 0`. В частности, это означает, что вы можете использовать 128-битную загрузку в своём коде.

**Замечания**:
* внутри функции `Softmax` ничего аллоцировать и копировать **не следует** (в том числе аллоцировать буферы для хранения промежуточных переменных)
* ожидается, что при работе функции `Softmax` будет вызываться не более одного кернела; вы можете написать разные кернелы для разных стадий алгоритма, но мы не гарантируем, что такой подход укладывается в ограничения по времени в бенчмарках
